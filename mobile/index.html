ⓘ How to judge — the 6 levels

Judge the idea, not the imagery. First ask: what practical lesson does each saying teach?

✏️ Typos & old spellings — OCR sometimes garbles words ("ivants" = "wants"). If you can still read the intended saying, judge its meaning and tap ✏️ to suggest the fix. Use "isn't a saying" only for text that is no proverb at all.

👯 Exact duplicate — both fields show the very same proverb, word for word (or trivially so: spelling/punctuation). Happens when two collections recorded the same saying.

🎯 Same rule — same rule or conclusion; only the wording differs. Test: explaining one gives almost exactly the explanation of the other.

🤝 Same advice — different metaphor, same practical recommendation. Test: I'd use either to advise someone in the same situation.

🧩 Same theme — same general topic, but not necessarily the same lesson. Test: they answer the same general problem.

🔗 Related, different lesson — same situation, different conclusions. Test: could appear in one discussion without saying the same thing.

⚔️ Contradictory — incompatible advice. Test: following one breaks the other.

➖ Unrelated — strip the metaphors and no important idea is shared.

If several fit, choose the highest. If you don't understand a saying, use Skip. Scheme: Dr. Elena Pelican.
